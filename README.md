# Counter app

A small counter built with [React](https://react.dev/) and bundled with
[Vite](https://vite.dev/). Tests run with [Vitest](https://vitest.dev/) and
React Testing Library.

## Behaviour

- Five buttons: `+` (add 1), `-` (subtract 1), `reset` (back to 0), `+4`
  (add 4) and `x2` (double the value).
- The value is shown in red when it is above 10, in blue when it is below 0,
  and in black otherwise.
- The heading shows `Counter` until the first click, then
  `Counter (N clicks)` with the number of recognised button clicks so far.

## Prerequisites

- Node.js `^20.19.0 || >=22.12.0` (the range declared in `package.json`
  `engines`)
- npm (bundled with Node.js)

## Getting started

Install dependencies:

```sh
npm install
```

Start the dev server with hot reload:

```sh
npm run dev
```

Run the test suite once:

```sh
npm test
```

Create a production build in `dist/`:

```sh
npm run build
```

Serve the built `dist/` folder locally with Vite:

```sh
npm run preview
```

## Serving the build

`npm run build` emits static files into `dist/`. Vite is configured with
`base: './'`, so asset URLs are relative and the `dist` folder can be hosted
from any path by any static file server (for example `npx serve dist` or
`python3 -m http.server --directory dist`).

The page loads a module script, so it must be served over HTTP. Opening
`dist/index.html` directly through a `file://` URL will not work.

## Project structure

```
index.html                    HTML entry point, loads src/main.jsx
style.css                     Styles for the counter
vite.config.js                Vite and Vitest configuration (base './', jsdom)
package.json                  Scripts, dependencies and Node engine range
src/main.jsx                  Mounts the React app
src/Counter.jsx               Counter component (buttons, heading, value colour)
src/counterReducer.js         State reducer and the ACTION constants
src/Counter.test.jsx          Component tests
src/counterReducer.test.js    Reducer tests
docs/adr/                     Architecture decision records
dist/                         Build output (generated by npm run build)
```

State lives in a `useReducer` in `Counter.jsx`. Every recognised action goes
through `counterReducer`, which updates the value and increments the click
count; unrecognised actions leave the state unchanged.
